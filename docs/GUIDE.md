## 📥 Part 1. Download and start

There is nothing to install. It is one file: download it and click it.

### Step 1. Click the green button

<a href="https://github.com/MRGREGOR85/WG-INSTALLING-BETA/raw/main/download/WG-Installing.exe"><img src="images/download_en.png" alt="Download WG Installing" width="420"></a>

Your browser downloads the file **WG-Installing.exe**.

### Step 2. Open the downloaded file

- Click the downloaded file in the **top right corner** of your browser,
- or open the **Downloads** folder and double-click **WG-Installing.exe**.

> 💡 **Tip:** drag the file from *Downloads* onto your **Desktop**. Next time you will find it straight away.

### Step 3. A blue window? That's fine

The first time, Windows may show a blue window: *"Windows protected your PC"*.
This is normal for small, free programs.

1. Click **More info**.
2. Click **Run anyway**.

<img src="images/smartscreen_en.png" alt="Blue Windows window" width="640">

### Step 4. Windows asks for permission: click "Yes"

The screen dims for a moment and Windows asks: *"Do you want to allow this app to make changes to your device?"*.
Click **Yes**. This way the program doesn't have to ask again for every single install.

> 🔧 The first time, the program checks whether your computer has everything it needs.
> If something is missing, it asks: *"Install them automatically now?"*. Click **Yes** and it downloads them from the official websites.

✅ The program is running!

## 🖱️ Part 2. Install, update, remove

### Step 5. Install a new program

**First, find the program:**

1. Type its name at the top, for example `firefox`, `vlc` or `7zip`.
2. Click **SEARCH** (or press Enter).

<img src="steps/s1_search_en.png" alt="Searching for a program" width="760">

**Then install it:**

1. Click the tile of the program you want. A ✔ appears in its corner.
2. Click **INSTALL** at the bottom.

<img src="steps/s2_install_en.png" alt="Installing a program" width="760">

The program asks if you are sure. Click **Yes** and wait. You can watch the progress in the black area at the bottom.

> 💡 You can tick several tiles at once. They install one after another.

### Step 6. Update your programs (once a week is great)

1. Click **UPDATES** at the top. You see the programs that have a newer version.
2. Click **UPDATE ALL**.

<img src="steps/s3_updates_en.png" alt="Updates" width="760">

Each tile shows the old and the new version, for example **24.07 → 24.08**.

> 💡 Only want to update one program? Tick its tile and click **UPDATE**.<br>
> Never want a program to update? Tick it and click **IGNORE**.

### Step 7. Remove a program you don't want any more

1. Click **INSTALLED** at the top. You see the programs on your computer.
2. Click the tile of the program to remove.
3. Click **UNINSTALL**.

<img src="steps/s4_uninstall_en.png" alt="Uninstalling" width="760">

The program asks *"Really UNINSTALL?"*. Click **Yes** only when you are sure.

## ⚙️ Part 3. Settings

Click **⚙** in the top right corner.

<img src="steps/s5_settings_btn_en.png" alt="Settings button" width="760">

1. **Language:** 7 languages. Click the arrows **‹ ›** until you see yours.
2. **Appearance:** 21 colour themes. Click until you like it.
3. **Run as administrator:** when it is on, Windows asks only once at the start (Step 4).

<img src="steps/s6_settings_en.png" alt="Settings" width="760">

Further down: checking for updates at startup, Windows updates, the list of ignored programs and the licence.
To go back, click **‹ BACK**.

## ✨ Part 4. Extras

### 💾 New computer? Take your programs with you

1. On the **old** computer, click **SAVE LIST** and save the file (for example on a USB stick).
2. On the **new** computer, click **LOAD LIST** and choose that file.

<img src="steps/s7_lists_en.png" alt="Save and load list" width="760">

All the programs install by themselves. The ones you already have are skipped.

### 🪟 Windows updates

Click **WINDOWS UPDATE**. The program shows which Windows updates are waiting and asks before installing anything.

<img src="steps/s8_windows_en.png" alt="Windows Update" width="760">

### 🔀 Other app stores

The **‹ WinGet ›** arrows at the top change where the program gets apps from:
**WinGet**, **Microsoft Store**, **PowerShell Gallery**, **Pip**, **Chocolatey**, **Scoop** and **Ninite**.
The buttons work the same in each one. If you are not sure, leave it on **WinGet**.

<img src="steps/s9_source_en.png" alt="Choosing a source" width="760">

## 🆘 Something is not working?

| What I see | What to do |
|---|---|
| Blue window *"Windows protected your PC"* | **More info** → **Run anyway**. See [Step 3](#step-3-a-blue-window-thats-fine). |
| The browser says the file *"isn't commonly downloaded"* | Click **⋯** next to the file → **Keep** → **Show more** → **Keep anyway**. |
| My antivirus warns me | This is common for small programs without a paid signature. Programs are installed by winget, Microsoft's own tool. |
| *"winget was not found"* | Install **App Installer** from the Microsoft Store, or click **Yes** when the program offers to install it. |
| The screen dims at every start | That's Windows asking for permission. Turn it off in **⚙** → *Run as administrator*. |
| A tile shows a letter instead of a picture | The picture downloads in the background. Wait a moment; it needs the internet. |
| It takes a while to start | It unpacks itself for a few seconds first. That is normal. |
| I want the settings back to new | Close the program. Type `%APPDATA%` in the folder address bar and delete the **WG Installing** folder. |
