## How to start

1. Click the green **Download** button above.
2. Open **WG-Installing.exe** from your Downloads folder.
3. If a blue window says *"Windows protected your PC"*, click **More info**, then **Run anyway**.
4. Windows asks for permission. Click **Yes**.

<p align="center"><img src="docs/images/smartscreen_en.png" alt="Click More info, then Run anyway" width="520"></p>

That's it. Not sure what to click next? 👉 **[Step-by-step guide with pictures](docs/GUIDE.md)**

## What it does

| Feature | What it means |
|---|---|
| **Search and install** | Type a name, tick the programs, click **INSTALL**. Several at once. |
| **Update everything** | One click on **UPDATE ALL** keeps all your programs up to date. |
| **Smart updating** | If an open program blocks an update, it is closed and opened again afterwards. |
| **Uninstall** | Remove programs you no longer need. |
| **Windows Update** | See waiting Windows updates and install them. |
| **7 sources** | WinGet, Microsoft Store, PowerShell Gallery, Pip, Chocolatey, Scoop and Ninite. |
| **Move to a new PC** | Save your program list and install everything on another computer. |
| **Your style** | 7 languages and 21 colour themes. |
| **Private** | No ads, no tracking, no account. |

## Questions

<details>
<summary><b>Is it safe?</b></summary>
<br>
WG Installing doesn't contain any programs itself. It uses <b>winget</b>, Microsoft's official tool, or the source you choose. It always asks before installing, updating or removing anything.
</details>

<details>
<summary><b>My browser or antivirus warns about the file.</b></summary>
<br>
Small free programs without a paid signature often get this warning by mistake. In the browser choose <b>Keep</b>. In the blue Windows window click <b>More info → Run anyway</b>.
</details>

<details>
<summary><b>Why does the screen dim when it starts?</b></summary>
<br>
That is Windows asking for permission, because installing programs needs it. You can turn it off in ⚙ Settings → <i>Run as administrator</i>.
</details>

<details>
<summary><b>It says "winget was not found".</b></summary>
<br>
Click <b>Yes</b> when the program offers to install it, or install <b>App Installer</b> from the Microsoft Store.
</details>
