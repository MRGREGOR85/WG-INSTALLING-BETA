## 📖 Cara pakai, langkah demi langkah

🟥 Bingkai merah menunjukkan **tempat untuk diklik**. 🔴 Angka **1**, **2**, **3** menunjukkan **apa yang diklik lebih dulu**.

### 📥 Langkah 1. Unduh

Klik tombol hijau **Download** di bagian atas halaman ini. Browser mengunduh satu file: **WG-Installing.exe**.

### 📂 Langkah 2. Buka file yang diunduh

- Klik file yang diunduh di **pojok kanan atas** browser,
- atau buka folder **Downloads** dan klik dua kali **WG-Installing.exe**.

> 💡 **Tips:** seret file dari *Downloads* ke **Desktop**. Lain kali kamu langsung menemukannya.

### 🛡️ Langkah 3. Jendela biru? Tidak apa-apa

Pertama kali, Windows mungkin menampilkan jendela biru: *“Windows melindungi PC Anda”*.
Ini normal untuk program kecil yang gratis.

1. Klik **Info selengkapnya**.
2. Klik **Tetap jalankan**.

<img src="../docs/images/smartscreen_en.png" alt="Jendela biru Windows" width="640">

### ✅ Langkah 4. Windows meminta izin: klik “Ya”

Layar meredup sesaat dan Windows bertanya: *“Apakah Anda ingin mengizinkan aplikasi ini membuat perubahan pada perangkat Anda?”*.
Klik **Ya**. Dengan begitu program tidak perlu bertanya lagi di setiap pemasangan.

> 🔧 Pertama kali, program memeriksa apakah komputermu punya semua yang diperlukan.
> Jika ada yang kurang, program bertanya: *“Install them automatically now?”*. Klik **Ya** dan program mengunduhnya dari situs resmi.

✅ Program berjalan!

## 🖱️ Bagian 2. Pasang, perbarui, hapus

### 🔎 Langkah 5. Pasang program baru

**Pertama, cari programnya:**

1. Ketik namanya di atas, misalnya `firefox`, `vlc`, atau `7zip`.
2. Klik **SEARCH** (atau tekan Enter).

<img src="../docs/steps/s1_search_en.png" alt="Mencari program" width="760">

**Lalu pasang:**

1. Klik ubin program yang kamu mau. Tanda ✔ muncul di pojoknya.
2. Klik **INSTALL** di bawah.

<img src="../docs/steps/s2_install_en.png" alt="Memasang program" width="760">

Program bertanya apakah kamu yakin. Klik **Ya** dan tunggu. Kemajuannya terlihat di area hitam di bawah.

> 💡 Kamu bisa mencentang beberapa ubin sekaligus. Semuanya dipasang satu per satu.

### ⬆️ Langkah 6. Perbarui programmu (seminggu sekali sudah bagus)

1. Klik **UPDATES** di atas. Kamu melihat program yang punya versi lebih baru.
2. Klik **UPDATE ALL**.

<img src="../docs/steps/s3_updates_en.png" alt="Pembaruan" width="760">

Setiap ubin menunjukkan versi lama dan baru, misalnya **24.07 → 24.08**.

> 💡 Hanya ingin memperbarui satu program? Centang ubinnya lalu klik **UPDATE**.<br>
> Tidak ingin sebuah program diperbarui sama sekali? Centang lalu klik **IGNORE**.

### 🗑️ Langkah 7. Hapus program yang tidak kamu inginkan lagi

1. Klik **INSTALLED** di atas. Kamu melihat program di komputermu.
2. Klik ubin program yang akan dihapus.
3. Klik **UNINSTALL**.

<img src="../docs/steps/s4_uninstall_en.png" alt="Mencopot" width="760">

Program bertanya *“Really UNINSTALL?”*. Klik **Ya** hanya jika kamu yakin.

## ⚙️ Bagian 3. Pengaturan

Klik **⚙** di pojok kanan atas.

<img src="../docs/steps/s5_settings_btn_en.png" alt="Tombol pengaturan" width="760">

1. **Bahasa:** 7 bahasa. Klik panah **‹ ›** sampai bahasamu muncul.
2. **Tampilan:** 21 tema warna. Klik sampai kamu suka.
3. **Jalankan sebagai administrator:** jika aktif, Windows hanya bertanya sekali saat mulai (Langkah 4).

<img src="../docs/steps/s6_settings_en.png" alt="Pengaturan" width="760">

Lebih bawah: cek pembaruan saat mulai, pembaruan Windows, daftar program yang diabaikan, dan lisensi.
Untuk kembali, klik **‹ BACK**.

---

## ✨ Bagian 4. Tambahan

### 💾 Komputer baru? Bawa programmu

1. Di komputer **lama**, klik **SAVE LIST** dan simpan file-nya (misalnya di flashdisk).
2. Di komputer **baru**, klik **LOAD LIST** dan pilih file itu.

<img src="../docs/steps/s7_lists_en.png" alt="Simpan dan muat daftar" width="760">

Semua program terpasang sendiri. Yang sudah ada akan dilewati.

### 🪟 Pembaruan Windows

Klik **WINDOWS UPDATE**. Program menunjukkan pembaruan Windows yang menunggu dan bertanya sebelum memasang apa pun.

<img src="../docs/steps/s8_windows_en.png" alt="Windows Update" width="760">

### 🔀 Toko aplikasi lainnya

Panah **‹ WinGet ›** di atas mengubah dari mana program mengambil aplikasi:
**WinGet**, **Microsoft Store**, **PowerShell Gallery**, **Pip**, **Chocolatey**, **Scoop** dan **Ninite**.
Tombolnya bekerja sama di semua sumber. Jika ragu, biarkan di **WinGet**.

<img src="../docs/steps/s9_source_en.png" alt="Memilih sumber" width="760">

## 🆘 Ada yang tidak berfungsi?

| Yang saya lihat | Yang harus dilakukan |
|---|---|
| Jendela biru *“Windows melindungi PC Anda”* | **Info selengkapnya** → **Tetap jalankan**. Lihat Langkah 3 di atas. |
| Browser bilang file ini *“jarang diunduh”* | Klik **⋯** di samping file → **Simpan** → **Tampilkan lainnya** → **Tetap simpan**. |
| Antivirus memberi peringatan | Ini umum untuk program kecil tanpa tanda tangan berbayar. Program dipasang oleh winget, alat milik Microsoft sendiri. |
| *"winget was not found"* | Pasang **App Installer** dari Microsoft Store, atau klik **Ya** saat program menawarkan untuk memasangnya. |
| Layar meredup setiap kali mulai | Itu Windows yang meminta izin. Matikan di **⚙** → *Jalankan sebagai administrator*. |
| Ubin menampilkan huruf, bukan gambar | Gambar diunduh di latar belakang. Tunggu sebentar; perlu internet. |
| Lama saat dibuka | Program mengekstrak dirinya dulu selama beberapa detik. Itu normal. |
| Saya ingin pengaturan kembali seperti baru | Tutup program. Ketik `%APPDATA%` di bilah alamat folder lalu hapus folder **WG Installing**. |

Masih buntu? Tulis di GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Apakah aman?

WG Installing sendiri tidak berisi program apa pun. Ia memakai <b>winget</b>, alat resmi Microsoft, atau sumber yang kamu pilih. Ia selalu bertanya sebelum memasang, memperbarui, atau menghapus apa pun.
