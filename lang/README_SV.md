## Vad det gör

| Funktion | Vad det betyder |
|---|---|
| **Sök och installera** | Skriv ett namn, kryssa i programmen, klicka på **INSTALL**. Flera på en gång. |
| **Uppdatera allt** | Ett klick på **UPDATE ALL** håller alla dina program uppdaterade. |
| **Smart uppdatering** | Om ett öppet program blockerar en uppdatering stängs det och öppnas igen efteråt. |
| **Avinstallera** | Ta bort program du inte längre behöver. |
| **Windows Update** | Se väntande Windows-uppdateringar och installera dem. |
| **7 källor** | WinGet, Microsoft Store, PowerShell Gallery, Pip, Chocolatey, Scoop och Ninite. |
| **Flytta till en ny dator** | Spara din programlista och installera allt på en annan dator. |
| **Din stil** | 7 språk och 21 färgteman. |
| **Privat** | Ingen reklam, ingen spårning, inget konto. |

## 📖 Så använder du det, steg för steg

🟥 En röd ram visar **var du klickar**. 🔴 Siffrorna **1**, **2**, **3** visar **vad du klickar på först**.

### 📥 Steg 1. Ladda ner

Klicka på den gröna knappen **Download** högst upp på sidan. Webbläsaren laddar ner en fil: **WG-Installing.exe**.

### 📂 Steg 2. Öppna den nedladdade filen

- Klicka på den nedladdade filen i webbläsarens **övre högra hörn**,
- eller öppna mappen **Hämtade filer** och dubbelklicka på **WG-Installing.exe**.

> 💡 **Tips:** dra filen från *Hämtade filer* till **Skrivbordet**. Nästa gång hittar du den direkt.

### 🛡️ Steg 3. Ett blått fönster? Det är lugnt

Första gången kan Windows visa ett blått fönster: *”Datorn skyddades av Windows”*.
Det är normalt för små gratisprogram.

1. Klicka på **Mer information**.
2. Klicka på **Kör ändå**.

<img src="../docs/images/smartscreen_en.png" alt="Blått Windows-fönster" width="640">

### ✅ Steg 4. Windows ber om lov: klicka på ”Ja”

Skärmen mörknar en stund och Windows frågar: *”Vill du tillåta att den här appen gör ändringar på din enhet?”*.
Klicka på **Ja**. Då behöver programmet inte fråga igen vid varje installation.

> 🔧 Första gången kontrollerar programmet att datorn har allt som behövs.
> Om något saknas frågar det: *”Install them automatically now?”*. Klicka på **Ja** så laddas det ner från de officiella webbplatserna.

✅ Programmet körs!

## 🖱️ Del 2. Installera, uppdatera, ta bort

### 🔎 Steg 5. Installera ett nytt program

**Hitta först programmet:**

1. Skriv namnet högst upp, till exempel `firefox`, `vlc` eller `7zip`.
2. Klicka på **SEARCH** (eller tryck på Enter).

<img src="../docs/steps/s1_search_en.png" alt="Söka efter ett program" width="760">

**Installera det sedan:**

1. Klicka på rutan för programmet du vill ha. En ✔ visas i hörnet.
2. Klicka på **INSTALL** längst ner.

<img src="../docs/steps/s2_install_en.png" alt="Installera ett program" width="760">

Programmet frågar om du är säker. Klicka på **Ja** och vänta. Förloppet syns i det svarta fältet längst ner.

> 💡 Du kan kryssa i flera rutor samtidigt. De installeras en efter en.

### ⬆️ Steg 6. Uppdatera dina program (en gång i veckan är toppen)

1. Klicka på **UPDATES** högst upp. Du ser programmen som har en nyare version.
2. Klicka på **UPDATE ALL**.

<img src="../docs/steps/s3_updates_en.png" alt="Uppdateringar" width="760">

Varje ruta visar den gamla och nya versionen, till exempel **24.07 → 24.08**.

> 💡 Vill du bara uppdatera ett program? Kryssa i dess ruta och klicka på **UPDATE**.<br>
> Vill du aldrig uppdatera ett visst program? Kryssa i det och klicka på **IGNORE**.

### 🗑️ Steg 7. Ta bort ett program du inte vill ha längre

1. Klicka på **INSTALLED** högst upp. Du ser programmen på datorn.
2. Klicka på rutan för programmet som ska bort.
3. Klicka på **UNINSTALL**.

<img src="../docs/steps/s4_uninstall_en.png" alt="Avinstallera" width="760">

Programmet frågar *”Really UNINSTALL?”*. Klicka på **Ja** bara när du är säker.

## ⚙️ Del 3. Inställningar

Klicka på **⚙** i övre högra hörnet.

<img src="../docs/steps/s5_settings_btn_en.png" alt="Inställningsknapp" width="760">

1. **Språk:** 7 språk. Klicka på pilarna **‹ ›** tills du ser ditt.
2. **Utseende:** 21 färgteman. Klicka tills du gillar det.
3. **Kör som administratör:** när det är på frågar Windows bara en gång vid start (Steg 4).

<img src="../docs/steps/s6_settings_en.png" alt="Inställningar" width="760">

Längre ner: sök efter uppdateringar vid start, Windows-uppdateringar, listan över ignorerade program och licensen.
Gå tillbaka med **‹ BACK**.

---

## ✨ Del 4. Extra

### 💾 Ny dator? Ta med dina program

1. På den **gamla** datorn klickar du på **SAVE LIST** och sparar filen (till exempel på ett USB-minne).
2. På den **nya** datorn klickar du på **LOAD LIST** och väljer den filen.

<img src="../docs/steps/s7_lists_en.png" alt="Spara och läs in lista" width="760">

Alla program installeras av sig själva. De du redan har hoppas över.

### 🪟 Windows-uppdateringar

Klicka på **WINDOWS UPDATE**. Programmet visar vilka Windows-uppdateringar som väntar och frågar innan något installeras.

<img src="../docs/steps/s8_windows_en.png" alt="Windows Update" width="760">

### 🔀 Andra appbutiker

Pilarna **‹ WinGet ›** högst upp ändrar var programmet hämtar appar ifrån:
**WinGet**, **Microsoft Store**, **PowerShell Gallery**, **Pip**, **Chocolatey**, **Scoop** och **Ninite**.
Knapparna fungerar likadant i alla. Om du är osäker, låt det stå på **WinGet**.

<img src="../docs/steps/s9_source_en.png" alt="Välja en källa" width="760">

## 🆘 Fungerar något inte?

| Vad jag ser | Vad jag gör |
|---|---|
| Blått fönster *”Datorn skyddades av Windows”* | **Mer information** → **Kör ändå**. Se Steg 3 ovan. |
| Webbläsaren säger att filen *”inte laddas ner så ofta”* | Klicka på **⋯** bredvid filen → **Behåll** → **Visa mer** → **Behåll ändå**. |
| Mitt antivirus varnar | Det är vanligt för små program utan betald signatur. Programmen installeras av winget, Microsofts eget verktyg. |
| *"winget was not found"* | Installera **Appinstallationsprogram** från Microsoft Store, eller klicka på **Ja** när programmet erbjuder sig att installera det. |
| Skärmen mörknar vid varje start | Det är Windows som ber om lov. Stäng av det i **⚙** → *Kör som administratör*. |
| En ruta visar en bokstav i stället för en bild | Bilden laddas ner i bakgrunden. Vänta en stund; internet behövs. |
| Det tar en stund att starta | Det packar först upp sig själv i några sekunder. Det är normalt. |
| Jag vill ha inställningarna som nya | Stäng programmet. Skriv `%APPDATA%` i mappens adressfält och ta bort mappen **WG Installing**. |

Fortfarande fast? Skriv på GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)
