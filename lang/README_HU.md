## Mit tud

| Funkció | Mit jelent |
|---|---|
| **Keresés és telepítés** | Írj be egy nevet, jelöld be a programokat, kattints az **INSTALL** gombra. Egyszerre többet is. |
| **Minden frissítése** | Egy kattintás az **UPDATE ALL** gombra, és minden programod naprakész. |
| **Okos frissítés** | Ha egy megnyitott program akadályozza a frissítést, bezárja, majd utána újra megnyitja. |
| **Eltávolítás** | Távolítsd el a programokat, amelyekre már nincs szükséged. |
| **Windows Update** | Lásd a várakozó Windows-frissítéseket, és telepítsd őket. |
| **7 forrás** | WinGet, Microsoft Store, PowerShell Gallery, Pip, Chocolatey, Scoop és Ninite. |
| **Költözés új gépre** | Mentsd el a programlistádat, és telepíts mindent egy másik gépre. |
| **A stílusod** | 7 nyelv és 21 színtéma. |
| **Privát** | Nincs reklám, nincs követés, nincs fiók. |

## 📖 Használat lépésről lépésre

🟥 A piros keret mutatja, **hova kattints**. 🔴 A **1**, **2**, **3** számok mutatják, **mire kattints először**.

### 📥 Lépés 1. Letöltés

Kattints az oldal tetején a zöld **Download** gombra. A böngésző letölt egy fájlt: **WG-Installing.exe**.

### 📂 Lépés 2. Nyisd meg a letöltött fájlt

- Kattints a letöltött fájlra a böngésző **jobb felső sarkában**,
- vagy nyisd meg a **Letöltések** mappát, és kattints duplán a(z) **WG-Installing.exe** fájlra.

> 💡 **Tipp:** húzd a fájlt a *Letöltésekből* az **Asztalra**. Legközelebb azonnal megtalálod.

### 🛡️ Lépés 3. Kék ablak? Semmi gond

Első alkalommal a Windows kék ablakot mutathat: *„A Windows megvédte a számítógépet”*.
Ez kis ingyenes programoknál normális.

1. Kattints a **További információ** lehetőségre.
2. Kattints a **Futtatás mindenképp** gombra.

<img src="../docs/images/smartscreen_en.png" alt="Kék Windows-ablak" width="640">

### ✅ Lépés 4. A Windows engedélyt kér: kattints az „Igen” gombra

A képernyő egy pillanatra elsötétül, és a Windows megkérdezi: *„Engedélyezi, hogy ez az alkalmazás módosításokat hajtson végre az eszközén?”*.
Kattints az **Igen** gombra. Így a programnak nem kell minden telepítésnél újra kérdeznie.

> 🔧 Első alkalommal a program ellenőrzi, megvan-e minden a gépen, ami kell.
> Ha valami hiányzik, megkérdezi: *„Install them automatically now?”*. Kattints az **Igen** gombra, és letölti a hivatalos oldalakról.

✅ A program fut!

## 🖱️ Rész 2. Telepítés, frissítés, eltávolítás

### 🔎 Lépés 5. Új program telepítése

**Előbb keresd meg a programot:**

1. Írd be fent a nevét, például `firefox`, `vlc` vagy `7zip`.
2. Kattints a **SEARCH** gombra (vagy nyomj Entert).

<img src="../docs/steps/s1_search_en.png" alt="Program keresése" width="760">

**Aztán telepítsd:**

1. Kattints a kívánt program csempéjére. A sarkában megjelenik egy ✔.
2. Kattints lent az **INSTALL** gombra.

<img src="../docs/steps/s2_install_en.png" alt="Program telepítése" width="760">

A program megkérdezi, biztos vagy-e benne. Kattints az **Igen** gombra, és várj. Az előrehaladást a lenti fekete területen látod.

> 💡 Egyszerre több csempét is bejelölhetsz. Egymás után települnek.

### ⬆️ Lépés 6. Frissítsd a programjaidat (hetente egyszer remek)

1. Kattints fent az **UPDATES** gombra. Látod a programokat, amelyeknek van újabb verziója.
2. Kattints az **UPDATE ALL** gombra.

<img src="../docs/steps/s3_updates_en.png" alt="Frissítések" width="760">

Minden csempe mutatja a régi és az új verziót, például **24.07 → 24.08**.

> 💡 Csak egy programot frissítenél? Jelöld be a csempéjét, és kattints az **UPDATE** gombra.<br>
> Egy programot sosem akarsz frissíteni? Jelöld be, és kattints az **IGNORE** gombra.

### 🗑️ Lépés 7. Távolítsd el a programot, amit már nem akarsz

1. Kattints fent az **INSTALLED** gombra. Látod a gépen lévő programokat.
2. Kattints az eltávolítandó program csempéjére.
3. Kattints az **UNINSTALL** gombra.

<img src="../docs/steps/s4_uninstall_en.png" alt="Eltávolítás" width="760">

A program megkérdezi: *„Really UNINSTALL?”*. Csak akkor kattints az **Igen** gombra, ha biztos vagy benne.

---

## ⚙️ Rész 3. Beállítások

Kattints a jobb felső sarokban a **⚙** gombra.

<img src="../docs/steps/s5_settings_btn_en.png" alt="Beállítások gomb" width="760">

1. **Nyelv:** 7 nyelv. Kattints a **‹ ›** nyilakra, amíg meg nem látod a tiédet.
2. **Megjelenés:** 21 színtéma. Kattints, amíg tetszik.
3. **Futtatás rendszergazdaként:** ha be van kapcsolva, a Windows csak egyszer kérdez induláskor (4. lépés).

<img src="../docs/steps/s6_settings_en.png" alt="Beállítások" width="760">

Lejjebb: frissítések keresése induláskor, Windows-frissítések, a figyelmen kívül hagyott programok listája és a licenc.
Visszalépni a **‹ BACK** gombbal lehet.

---

## ✨ Rész 4. Extrák

### 💾 Új gép? Vidd magaddal a programjaidat

1. A **régi** gépen kattints a **SAVE LIST** gombra, és mentsd el a fájlt (például pendrive-ra).
2. Az **új** gépen kattints a **LOAD LIST** gombra, és válaszd ki azt a fájlt.

<img src="../docs/steps/s7_lists_en.png" alt="Lista mentése és betöltése" width="760">

Minden program magától települ. A meglévőket kihagyja.

### 🪟 Windows-frissítések

Kattints a **WINDOWS UPDATE** gombra. A program megmutatja, mely Windows-frissítések várakoznak, és kérdez, mielőtt bármit telepítene.

<img src="../docs/steps/s8_windows_en.png" alt="Windows Update" width="760">

### 🔀 Más alkalmazásboltok

A fenti **‹ WinGet ›** nyilak azt állítják, honnan veszi a program az alkalmazásokat:
**WinGet**, **Microsoft Store**, **PowerShell Gallery**, **Pip**, **Chocolatey**, **Scoop** és **Ninite**.
A gombok mindenhol ugyanúgy működnek. Ha nem vagy biztos, hagyd **WinGet**-en.

<img src="../docs/steps/s9_source_en.png" alt="Forrás kiválasztása" width="760">

## 🆘 Valami nem működik?

| Amit látok | Mit tegyek |
|---|---|
| Kék ablak *„A Windows megvédte a számítógépet”* | **További információ** → **Futtatás mindenképp**. Lásd a fenti 3. lépést. |
| A böngésző szerint a fájlt *„nem gyakran töltik le”* | Kattints a fájl melletti **⋯** gombra → **Megtartás** → **Továbbiak** → **Megtartás mindenképp**. |
| A víruskereső figyelmeztet | Ez gyakori a fizetős aláírás nélküli kis programoknál. A programokat a winget telepíti, a Microsoft saját eszköze. |
| *"winget was not found"* | Telepítsd az **Alkalmazástelepítőt** a Microsoft Store-ból, vagy kattints az **Igen** gombra, amikor a program felajánlja. |
| Minden indításkor elsötétül a képernyő | Ez a Windows engedélykérése. Kikapcsolható: **⚙** → *Futtatás rendszergazdaként*. |
| Egy csempén betű látszik kép helyett | A kép a háttérben töltődik le. Várj egy kicsit; internet kell hozzá. |
| Lassan indul | Előbb pár másodpercig kicsomagolja magát. Ez normális. |
| Alaphelyzetbe akarom állítani a beállításokat | Zárd be a programot. Írd be a `%APPDATA%` címet a mappa címsorába, és töröld a(z) **WG Installing** mappát. |

Még mindig elakadtál? Írj a GitHubon: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Biztonságos?

A WG Installing maga nem tartalmaz programokat. A <b>winget</b>-et, a Microsoft hivatalos eszközét, vagy az általad választott forrást használja. Mindig kérdez, mielőtt bármit telepítene, frissítene vagy eltávolítana.
