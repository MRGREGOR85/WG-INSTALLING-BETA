## Was es kann

| Funktion | Was das bedeutet |
|---|---|
| **Suchen und installieren** | Namen eintippen, Programme anhaken, **INSTALL** klicken. Mehrere auf einmal. |
| **Alles aktualisieren** | Ein Klick auf **UPDATE ALL** hält alle Programme aktuell. |
| **Schlaues Aktualisieren** | Blockiert ein offenes Programm ein Update, wird es geschlossen und danach wieder geöffnet. |
| **Deinstallieren** | Entferne Programme, die du nicht mehr brauchst. |
| **Windows Update** | Wartende Windows-Updates sehen und installieren. |
| **7 Quellen** | WinGet, Microsoft Store, PowerShell Gallery, Pip, Chocolatey, Scoop und Ninite. |
| **Umzug auf einen neuen PC** | Speichere deine Programmliste und installiere alles auf einem anderen Computer. |
| **Dein Stil** | 7 Sprachen und 21 Farbthemen. |
| **Privat** | Keine Werbung, kein Tracking, kein Konto. |

## 📖 So geht's, Schritt für Schritt

🟥 Ein roter Rahmen zeigt, **wo du klicken musst**. 🔴 Die Zahlen **1**, **2**, **3** zeigen, **was du zuerst klickst**.

### 📥 Schritt 1. Herunterladen

Klicke oben auf dieser Seite auf den grünen **Download**-Knopf. Dein Browser lädt eine Datei herunter: **WG-Installing.exe**.

### 📂 Schritt 2. Die heruntergeladene Datei öffnen

- Klicke auf die heruntergeladene Datei **oben rechts** im Browser,
- oder öffne den Ordner **Downloads** und doppelklicke auf **WG-Installing.exe**.

> 💡 **Tipp:** Ziehe die Datei aus *Downloads* auf deinen **Desktop**. Dann findest du sie beim nächsten Mal sofort.

### 🛡️ Schritt 3. Ein blaues Fenster? Kein Problem

Beim ersten Mal zeigt Windows vielleicht ein blaues Fenster: *„Der Computer wurde durch Windows geschützt“*.
Das ist bei kleinen, kostenlosen Programmen normal.

1. Klicke auf **Weitere Informationen**.
2. Klicke auf **Trotzdem ausführen**.

<img src="../docs/images/smartscreen_en.png" alt="Blaues Windows-Fenster" width="640">

### ✅ Schritt 4. Windows fragt um Erlaubnis: „Ja“ klicken

Der Bildschirm wird kurz dunkler und Windows fragt: *„Möchten Sie zulassen, dass durch diese App Änderungen an Ihrem Gerät vorgenommen werden?“*.
Klicke auf **Ja**. So muss das Programm nicht bei jeder einzelnen Installation erneut fragen.

> 🔧 Beim ersten Mal prüft das Programm, ob dein Computer alles Nötige hat.
> Fehlt etwas, fragt es: *„Install them automatically now?“*. Klicke auf **Ja**, und es lädt es von den offiziellen Seiten herunter.

✅ Das Programm läuft!

## 🖱️ Teil 2. Installieren, aktualisieren, entfernen

### 🔎 Schritt 5. Ein neues Programm installieren

**Zuerst das Programm finden:**

1. Tippe oben seinen Namen ein, zum Beispiel `firefox`, `vlc` oder `7zip`.
2. Klicke auf **SEARCH** (oder drücke Enter).

<img src="../docs/steps/s1_search_en.png" alt="Ein Programm suchen" width="760">

**Dann installieren:**

1. Klicke auf die Kachel des gewünschten Programms. In ihrer Ecke erscheint ein ✔.
2. Klicke unten auf **INSTALL**.

<img src="../docs/steps/s2_install_en.png" alt="Ein Programm installieren" width="760">

Das Programm fragt, ob du sicher bist. Klicke auf **Ja** und warte. Den Fortschritt siehst du im schwarzen Bereich unten.

> 💡 Du kannst mehrere Kacheln auf einmal anhaken. Sie werden nacheinander installiert.

### ⬆️ Schritt 6. Programme aktualisieren (einmal pro Woche ist super)

1. Klicke oben auf **UPDATES**. Du siehst die Programme, für die es eine neuere Version gibt.
2. Klicke auf **UPDATE ALL**.

<img src="../docs/steps/s3_updates_en.png" alt="Updates" width="760">

Jede Kachel zeigt die alte und die neue Version, zum Beispiel **24.07 → 24.08**.

> 💡 Nur ein Programm aktualisieren? Hake seine Kachel an und klicke auf **UPDATE**.<br>
> Ein Programm soll nie aktualisiert werden? Hake es an und klicke auf **IGNORE**.

### 🗑️ Schritt 7. Ein Programm entfernen, das du nicht mehr willst

1. Klicke oben auf **INSTALLED**. Du siehst die Programme auf deinem Computer.
2. Klicke auf die Kachel des zu entfernenden Programms.
3. Klicke auf **UNINSTALL**.

<img src="../docs/steps/s4_uninstall_en.png" alt="Deinstallieren" width="760">

Das Programm fragt *„Really UNINSTALL?“*. Klicke nur auf **Ja**, wenn du sicher bist.

## ⚙️ Teil 3. Einstellungen

Klicke oben rechts auf **⚙**.

<img src="../docs/steps/s5_settings_btn_en.png" alt="Einstellungsknopf" width="760">

1. **Sprache:** 7 Sprachen. Klicke auf die Pfeile **‹ ›**, bis du deine siehst.
2. **Aussehen:** 21 Farbthemen. Klicke, bis es dir gefällt.
3. **Als Administrator ausführen:** Wenn es an ist, fragt Windows nur einmal beim Start (Schritt 4).

<img src="../docs/steps/s6_settings_en.png" alt="Einstellungen" width="760">

Weiter unten: Update-Prüfung beim Start, Windows-Updates, die Liste ignorierter Programme und die Lizenz.
Zurück geht es mit **‹ BACK**.

## ✨ Teil 4. Extras

### 💾 Neuer Computer? Nimm deine Programme mit

1. Klicke am **alten** Computer auf **SAVE LIST** und speichere die Datei (zum Beispiel auf einem USB-Stick).
2. Klicke am **neuen** Computer auf **LOAD LIST** und wähle diese Datei.

<img src="../docs/steps/s7_lists_en.png" alt="Liste speichern und laden" width="760">

Alle Programme installieren sich von selbst. Was du schon hast, wird übersprungen.

### 🪟 Windows-Updates

Klicke auf **WINDOWS UPDATE**. Das Programm zeigt, welche Windows-Updates warten, und fragt, bevor es etwas installiert.

<img src="../docs/steps/s8_windows_en.png" alt="Windows Update" width="760">

### 🔀 Andere App-Stores

Die Pfeile **‹ WinGet ›** oben ändern, woher das Programm die Apps holt:
**WinGet**, **Microsoft Store**, **PowerShell Gallery**, **Pip**, **Chocolatey**, **Scoop** und **Ninite**.
Die Knöpfe funktionieren überall gleich. Wenn du unsicher bist, lass es auf **WinGet**.

<img src="../docs/steps/s9_source_en.png" alt="Quelle wählen" width="760">

## 🆘 Etwas funktioniert nicht?

| Was ich sehe | Was tun |
|---|---|
| Blaues Fenster *„Der Computer wurde durch Windows geschützt“* | **Weitere Informationen** → **Trotzdem ausführen**. Siehe Schritt 3 oben. |
| Der Browser meldet, die Datei werde *„nicht häufig heruntergeladen“* | Klicke auf **⋯** neben der Datei → **Beibehalten** → **Mehr anzeigen** → **Trotzdem beibehalten**. |
| Mein Virenscanner warnt | Das ist bei kleinen Programmen ohne bezahlte Signatur üblich. Programme werden von winget installiert, dem Werkzeug von Microsoft selbst. |
| *"winget was not found"* | Installiere den **App-Installer** aus dem Microsoft Store oder klicke auf **Ja**, wenn das Programm die Installation anbietet. |
| Der Bildschirm wird bei jedem Start dunkel | Das ist Windows, das um Erlaubnis fragt. Abschalten unter **⚙** → *Als Administrator ausführen*. |
| Eine Kachel zeigt einen Buchstaben statt eines Bildes | Das Bild lädt im Hintergrund. Warte kurz; dafür braucht es Internet. |
| Der Start dauert etwas | Es entpackt sich zuerst ein paar Sekunden lang selbst. Das ist normal. |
| Ich will die Einstellungen wie neu | Schließe das Programm. Tippe `%APPDATA%` in die Adressleiste des Ordners und lösche den Ordner **WG Installing**. |

Kommst du nicht weiter? Schreib auf GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Ist es sicher?

WG Installing enthält selbst keine Programme. Es nutzt <b>winget</b>, das offizielle Werkzeug von Microsoft, oder die Quelle, die du wählst. Es fragt immer, bevor es etwas installiert, aktualisiert oder entfernt.
