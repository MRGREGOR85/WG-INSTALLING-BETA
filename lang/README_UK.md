## Що вміє

| Функція | Що це означає |
|---|---|
| **Пошук і встановлення** | Введи назву, познач програми, натисни **INSTALL**. Кілька одночасно. |
| **Оновити все** | Один клік на **UPDATE ALL**, і всі програми актуальні. |
| **Розумне оновлення** | Якщо відкрита програма блокує оновлення, її буде закрито, а потім знову відкрито. |
| **Видалення** | Видаляй програми, які більше не потрібні. |
| **Windows Update** | Переглядай очікувані оновлення Windows і встановлюй їх. |
| **7 джерел** | WinGet, Microsoft Store, PowerShell Gallery, Pip, Chocolatey, Scoop і Ninite. |
| **Переїзд на новий ПК** | Збережи список програм і встанови все на іншому комп'ютері. |
| **Твій стиль** | 7 мов і 21 кольорова тема. |
| **Приватно** | Без реклами, без стеження, без облікового запису. |

## 📖 Як користуватися, крок за кроком

🟥 Червона рамка показує, **куди натиснути**. 🔴 Цифри **1**, **2**, **3** показують, **що натиснути спочатку**.

### 📥 Крок 1. Завантаж

Натисни зелену кнопку **Download** угорі цієї сторінки. Браузер завантажить один файл: **WG-Installing.exe**.

### 📂 Крок 2. Відкрий завантажений файл

- Натисни на завантажений файл у **правому верхньому куті** браузера,
- або відкрий папку **Завантаження** і двічі натисни **WG-Installing.exe**.

> 💡 **Порада:** перетягни файл із *Завантажень* на **Робочий стіл**. Наступного разу знайдеш його одразу.

### 🛡️ Крок 3. Синє вікно? Усе гаразд

Першого разу Windows може показати синє вікно: *«Windows захистила ваш ПК»*.
Для маленьких безкоштовних програм це нормально.

1. Натисни **Докладніше**.
2. Натисни **Усе одно запустити**.

<img src="../docs/images/smartscreen_en.png" alt="Синє вікно Windows" width="640">

### ✅ Крок 4. Windows просить дозволу: натисни «Так»

Екран на мить темніє, і Windows питає: *«Дозволити цій програмі вносити зміни на вашому пристрої?»*.
Натисни **Так**. Тоді програмі не доведеться питати знову при кожному встановленні.

> 🔧 Першого разу програма перевіряє, чи є на комп'ютері все потрібне.
> Якщо чогось бракує, вона питає: *«Install them automatically now?»*. Натисни **Так**, і вона завантажить це з офіційних сайтів.

✅ Програма працює!

## 🖱️ Частина 2. Встановлення, оновлення, видалення

### 🔎 Крок 5. Встанови нову програму

**Спершу знайди програму:**

1. Введи її назву вгорі, наприклад `firefox`, `vlc` або `7zip`.
2. Натисни **SEARCH** (або Enter).

<img src="../docs/steps/s1_search_en.png" alt="Пошук програми" width="760">

**Потім встанови її:**

1. Натисни плитку потрібної програми. У її куті з'явиться ✔.
2. Натисни **INSTALL** унизу.

<img src="../docs/steps/s2_install_en.png" alt="Встановлення програми" width="760">

Програма спитає, чи ти впевнений. Натисни **Так** і зачекай. Перебіг видно в чорній області внизу.

> 💡 Можна позначити кілька плиток одразу. Вони встановляться одна за одною.

### ⬆️ Крок 6. Оновлюй програми (раз на тиждень — чудово)

1. Натисни **UPDATES** угорі. Побачиш програми, що мають новішу версію.
2. Натисни **UPDATE ALL**.

<img src="../docs/steps/s3_updates_en.png" alt="Оновлення" width="760">

Кожна плитка показує стару й нову версію, наприклад **24.07 → 24.08**.

> 💡 Хочеш оновити лише одну програму? Познач її плитку й натисни **UPDATE**.<br>
> Не хочеш ніколи оновлювати якусь програму? Познач її й натисни **IGNORE**.

### 🗑️ Крок 7. Видали програму, яка більше не потрібна

1. Натисни **INSTALLED** угорі. Побачиш програми на комп'ютері.
2. Натисни плитку програми, яку треба видалити.
3. Натисни **UNINSTALL**.

<img src="../docs/steps/s4_uninstall_en.png" alt="Видалення" width="760">

Програма спитає *«Really UNINSTALL?»*. Натискай **Так**, лише коли впевнений.

---

## ⚙️ Частина 3. Налаштування

Натисни **⚙** у правому верхньому куті.

<img src="../docs/steps/s5_settings_btn_en.png" alt="Кнопка налаштувань" width="760">

1. **Мова:** 7 мов. Натискай стрілки **‹ ›**, доки не побачиш свою.
2. **Вигляд:** 21 кольорова тема. Натискай, доки не сподобається.
3. **Запуск від імені адміністратора:** коли ввімкнено, Windows питає лише раз під час запуску (Крок 4).

<img src="../docs/steps/s6_settings_en.png" alt="Налаштування" width="760">

Нижче: перевірка оновлень під час запуску, оновлення Windows, список ігнорованих програм і ліцензія.
Щоб повернутися, натисни **‹ BACK**.

---

## ✨ Частина 4. Додатково

### 💾 Новий комп'ютер? Забери програми з собою

1. На **старому** комп'ютері натисни **SAVE LIST** і збережи файл (наприклад, на флешку).
2. На **новому** комп'ютері натисни **LOAD LIST** і вибери цей файл.

<img src="../docs/steps/s7_lists_en.png" alt="Збереження й завантаження списку" width="760">

Усі програми встановляться самі. Ті, що вже є, будуть пропущені.

### 🪟 Оновлення Windows

Натисни **WINDOWS UPDATE**. Програма покаже, які оновлення Windows чекають, і спитає, перш ніж щось встановити.

<img src="../docs/steps/s8_windows_en.png" alt="Windows Update" width="760">

### 🔀 Інші магазини застосунків

Стрілки **‹ WinGet ›** угорі змінюють, звідки програма бере застосунки:
**WinGet**, **Microsoft Store**, **PowerShell Gallery**, **Pip**, **Chocolatey**, **Scoop** і **Ninite**.
Кнопки всюди працюють однаково. Якщо не впевнений, залиш **WinGet**.

<img src="../docs/steps/s9_source_en.png" alt="Вибір джерела" width="760">

## 🆘 Щось не працює?

| Що я бачу | Що робити |
|---|---|
| Синє вікно *«Windows захистила ваш ПК»* | **Докладніше** → **Усе одно запустити**. Див. Крок 3 вище. |
| Браузер пише, що файл *«нечасто завантажують»* | Натисни **⋯** біля файлу → **Зберегти** → **Показати більше** → **Усе одно зберегти**. |
| Антивірус попереджає | Це часто трапляється з маленькими програмами без платного підпису. Програми встановлює winget, інструмент самої Microsoft. |
| *"winget was not found"* | Встанови **Інсталятор застосунків** з Microsoft Store або натисни **Так**, коли програма запропонує його встановити. |
| Екран темніє при кожному запуску | Це Windows просить дозволу. Вимкни в **⚙** → *Запуск від імені адміністратора*. |
| Плитка показує літеру замість картинки | Картинка завантажується у фоні. Зачекай трохи; потрібен інтернет. |
| Довго запускається | Спочатку кілька секунд розпаковується сама. Це нормально. |
| Хочу скинути налаштування | Закрий програму. Введи `%APPDATA%` в адресний рядок папки та видали папку **WG Installing**. |

## Чи це безпечно?

WG Installing сам не містить жодних програм. Він використовує <b>winget</b>, офіційний інструмент Microsoft, або джерело, яке ти обереш. Він завжди питає перед встановленням, оновленням чи видаленням.
