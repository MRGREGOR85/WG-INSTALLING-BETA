## Что умеет

| Функция | Что это значит |
|---|---|
| **Поиск и установка** | Введи название, отметь программы, нажми **INSTALL**. Несколько сразу. |

## 📖 Как пользоваться, шаг за шагом

🟥 Красная рамка показывает, **куда нажать**. 🔴 Цифры **1**, **2**, **3** показывают, **что нажать сначала**.

### 📥 Шаг 1. Скачай

Нажми зелёную кнопку **Download** вверху этой страницы. Браузер скачает один файл: **WG-Installing.exe**.

### 📂 Шаг 2. Открой скачанный файл

- Нажми на скачанный файл в **правом верхнем углу** браузера,
- или открой папку **Загрузки** и дважды щёлкни **WG-Installing.exe**.

> 💡 **Совет:** перетащи файл из *Загрузок* на **Рабочий стол**. В следующий раз найдёшь его сразу.

### 🛡️ Шаг 3. Синее окно? Всё в порядке

В первый раз Windows может показать синее окно: *«Система Windows защитила ваш компьютер»*.
Для небольших бесплатных программ это нормально.

1. Нажми **Подробнее**.
2. Нажми **Выполнить в любом случае**.

<img src="../docs/images/smartscreen_en.png" alt="Синее окно Windows" width="640">

### ✅ Шаг 4. Windows просит разрешения: нажми «Да»

Экран на миг темнеет, и Windows спрашивает: *«Разрешить этому приложению вносить изменения на вашем устройстве?»*.
Нажми **Да**. Тогда программе не придётся спрашивать снова при каждой установке.

> 🔧 В первый раз программа проверяет, есть ли на компьютере всё необходимое.
> Если чего-то не хватает, она спрашивает: *«Install them automatically now?»*. Нажми **Да**, и она скачает это с официальных сайтов.

✅ Программа работает!

## 🖱️ Часть 2. Установка, обновление, удаление

### 🔎 Шаг 5. Установи новую программу

**Сначала найди программу:**

1. Введи её название вверху, например `firefox`, `vlc` или `7zip`.
2. Нажми **SEARCH** (или Enter).

<img src="../docs/steps/s1_search_en.png" alt="Поиск программы" width="760">

**Потом установи её:**

1. Нажми плитку нужной программы. В её углу появится ✔.
2. Нажми **INSTALL** внизу.

<img src="../docs/steps/s2_install_en.png" alt="Установка программы" width="760">

Программа спросит, уверен ли ты. Нажми **Да** и подожди. Ход установки виден в чёрной области внизу.

> 💡 Можно отметить несколько плиток сразу. Они установятся по очереди.

### ⬆️ Шаг 6. Обновляй программы (раз в неделю — отлично)

1. Нажми **UPDATES** вверху. Увидишь программы, у которых есть новая версия.
2. Нажми **UPDATE ALL**.

<img src="../docs/steps/s3_updates_en.png" alt="Обновления" width="760">

Каждая плитка показывает старую и новую версию, например **24.07 → 24.08**.

> 💡 Хочешь обновить только одну программу? Отметь её плитку и нажми **UPDATE**.<br>
> Не хочешь никогда обновлять какую-то программу? Отметь её и нажми **IGNORE**.

### 🗑️ Шаг 7. Удали программу, которая больше не нужна

1. Нажми **INSTALLED** вверху. Увидишь программы на компьютере.
2. Нажми плитку программы, которую нужно удалить.
3. Нажми **UNINSTALL**.

<img src="../docs/steps/s4_uninstall_en.png" alt="Удаление" width="760">

Программа спросит *«Really UNINSTALL?»*. Нажимай **Да**, только если уверен.

## ⚙️ Часть 3. Настройки

Нажми **⚙** в правом верхнем углу.

<img src="../docs/steps/s5_settings_btn_en.png" alt="Кнопка настроек" width="760">

1. **Язык:** 7 языков. Нажимай стрелки **‹ ›**, пока не увидишь свой.
2. **Внешний вид:** 21 цветовая тема. Нажимай, пока не понравится.
3. **Запуск от имени администратора:** когда включено, Windows спрашивает только один раз при запуске (Шаг 4).

<img src="../docs/steps/s6_settings_en.png" alt="Настройки" width="760">

Ниже: проверка обновлений при запуске, обновления Windows, список игнорируемых программ и лицензия.
Чтобы вернуться, нажми **‹ BACK**.

## ✨ Часть 4. Дополнительно

### 💾 Новый компьютер? Забери программы с собой

1. На **старом** компьютере нажми **SAVE LIST** и сохрани файл (например, на флешку).
2. На **новом** компьютере нажми **LOAD LIST** и выбери этот файл.

<img src="../docs/steps/s7_lists_en.png" alt="Сохранение и загрузка списка" width="760">

Все программы установятся сами. Те, что уже есть, будут пропущены.

### 🪟 Обновления Windows

Нажми **WINDOWS UPDATE**. Программа покажет, какие обновления Windows ждут, и спросит, прежде чем что-то установить.

<img src="../docs/steps/s8_windows_en.png" alt="Windows Update" width="760">

### 🔀 Другие магазины приложений

Стрелки **‹ WinGet ›** вверху меняют, откуда программа берёт приложения:
**WinGet**, **Microsoft Store**, **PowerShell Gallery**, **Pip**, **Chocolatey**, **Scoop** и **Ninite**.
Кнопки везде работают одинаково. Если не уверен, оставь **WinGet**.

<img src="../docs/steps/s9_source_en.png" alt="Выбор источника" width="760">

## 🆘 Что-то не работает?

| Что я вижу | Что делать |
|---|---|
| Синее окно *«Система Windows защитила ваш компьютер»* | **Подробнее** → **Выполнить в любом случае**. См. Шаг 3 выше. |
| Браузер пишет, что файл *«скачивают нечасто»* | Нажми **⋯** рядом с файлом → **Сохранить** → **Показать больше** → **Всё равно сохранить**. |
| Антивирус предупреждает | Это обычное дело для небольших программ без платной подписи. Программы устанавливает winget, инструмент самой Microsoft. |
| *"winget was not found"* | Установи **Установщик приложений** из Microsoft Store или нажми **Да**, когда программа предложит его установить. |
| Экран темнеет при каждом запуске | Это Windows просит разрешения. Отключи в **⚙** → *Запуск от имени администратора*. |
| Плитка показывает букву вместо картинки | Картинка загружается в фоне. Подожди немного; нужен интернет. |
| Долго запускается | Сначала несколько секунд распаковывается сама. Это нормально. |
| Хочу сбросить настройки | Закрой программу. Введи `%APPDATA%` в адресную строку папки и удали папку **WG Installing**. |

Всё ещё не получается? Напиши на GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Это безопасно?

WG Installing сам не содержит программ. Он использует <b>winget</b>, официальный инструмент Microsoft, или выбранный тобой источник. Он всегда спрашивает перед установкой, обновлением или удалением.
